# `_incoming/` — staging drops for Michelle Diamond (canonical app)

**This is the only drop folder for new raw photos.**

Do **not** use `apps/diamonds-edge/public/images/` (retired Next review host).

## How to use

1. Drop the cleared JPEG/WebP here with a descriptive kebab name, e.g.  
   `orpheum-orchestra-choir.jpeg`
2. Add a one-line note under **Log** below (what it is, intended slot).
3. An agent wires it into a live slot:
   - Home hero → `src/assets/hero-orpheum.jpg` (or `public/gallery/hero/…`)
   - Section walls → `public/gallery/{about,luxury,opera,events,…}/`
4. Prefer WebP + IPTC ownership before public marketing if the brief requires it; JPEG is OK for staging.
